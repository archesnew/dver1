## 1. Синхронизация `item_kind` и сопоставление со ссылками Exclusive Arc

В таблице `order_items` классификатор `item_kind` полностью синхронизирован и строго сопоставлен с внешними ключами архитектуры Exclusive Arc:

| Тип позиции в заказе (`item_kind`) | Физический смысл комплектующей | Обязательный внешний ключ | Дополнительные ключи (строго `NULL`) |
| :--- | :--- | :--- | :--- |
| **`door_leaf`** | Межкомнатное дверное полотно | `variant_id` → `product_variants(id)` | `molding_id = NULL`, `hardware_variant_id = NULL` |
| **`monolithic_block`** | Стальной неделимый блок входной двери | `variant_id` → `product_variants(id)` | `molding_id = NULL`, `hardware_variant_id = NULL` |
| **`invisible_kit`** | Скрытый монокомплект под штукатурку | `variant_id` → `product_variants(id)` | `molding_id = NULL`, `hardware_variant_id = NULL` |
| **`frame`** | Стойка телескопической коробки МДФ | `molding_id` → `molding_items(id)` | `variant_id = NULL`, `hardware_variant_id = NULL` |
| **`casing`** | Стойка телескопического наличника | `molding_id` → `molding_items(id)` | `variant_id = NULL`, `hardware_variant_id = NULL` |
| **`extension`** | Планка телескопического добора | `molding_id` → `molding_items(id)` | `variant_id = NULL`, `hardware_variant_id = NULL` |
| **`h_beam`** | Соединительный Н-профиль для доборов | `molding_id` → `molding_items(id)` | `variant_id = NULL`, `hardware_variant_id = NULL` |
| **`hinge`** | Петля накладная / врезная / скрытая 3D | `hardware_variant_id` → `hardware_variants(id)` | `variant_id = NULL`, `molding_id = NULL` |
| **`lock`** | Замок магнитный / механический с планкой| `hardware_variant_id` → `hardware_variants(id)` | `variant_id = NULL`, `molding_id = NULL` |
| **`handle`** | Ручка дверная раздельная на розетке | `hardware_variant_id` → `hardware_variants(id)` | `variant_id = NULL`, `molding_id = NULL` |
| **`wc_turn`** | Завертка сантехническая поворотная | `hardware_variant_id` → `hardware_variants(id)` | `variant_id = NULL`, `molding_id = NULL` |
| **`escutcheon`** | Накладка декоративная под ключ/цилиндр | `hardware_variant_id` → `hardware_variants(id)` | `variant_id = NULL`, `molding_id = NULL` |

**Гарантия целостности:**  
Ограничение СУБД `CONSTRAINT chk_order_item_single_target CHECK (num_nonnulls(variant_id, molding_id, hardware_variant_id) = 1)` физически не позволяет допустить ошибку привязки типа комплектующей к внешним таблицам.

## 2. Сверка и валидация семи расчетных сценариев

Все 7 сценариев строго разграничены по составу, исключая двусмысленность:

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                      МАТРИЦА СОСТАВА 7 СЦЕНАРИЕВ                            │
├──────────────────────────┬──────────┬──────────┬──────────┬────────┬────────┤
│ Сценарий                 │ Полотно  │ Погонаж  │ 2 Петли  │ 1 Замок│ Ручка  │
├──────────────────────────┼──────────┼──────────┼──────────┼────────┼────────┤
│ 1. Только полотно        │ ДА (1.0) │ НЕТ (0)  │ НЕТ (0)  │ НЕТ (0)│ НЕТ (0)│
│ 2. Полотно + коробка     │ ДА (1.0) │ ДА (2.5) │ НЕТ (0)  │ НЕТ (0)│ НЕТ (0)│
│ 3. Комплект (1 ст. нал.) │ ДА (1.0) │ ДА (5.0) │ НЕТ (0)  │ НЕТ (0)│ НЕТ (0)│
│ 4. Комплект (2 ст. нал.) │ ДА (1.0) │ ДА (7.5) │ НЕТ (0)  │ НЕТ (0)│ НЕТ (0)│
│ 5. Комплект с доборами   │ ДА (1.0) │ ДА (10.0)│ НЕТ (0)  │ НЕТ (0)│ НЕТ (0)│
│ 6. СТАНДАРТ С ФУРНИТУРОЙ │ ДА (1.0) │ ДА (7.5) │ ДА (2.0) │ ДА(1.0)│ НЕТ (0)│
│ 7. ПОЛНЫЙ ПОД КЛЮЧ       │ ДА (1.0) │ ДА (7.5) │ ДА (2.0) │ ДА(1.0)│ ВЫБОР! │
└──────────────────────────┴──────────┴──────────┴──────────┴────────┴────────┘
```

### Формулы расчета:

1. **Сценарий 1: «Только полотно» (`leaf_only`):**  
   $$P = P_{leaf}$$
2. **Сценарий 2: «Полотно с коробкой» (`leaf_with_frame`):**  
   $$P = P_{leaf} + 2.5 \times P_{frame}$$
3. **Сценарий 3: «Комплект с наличниками на 1 сторону» (`kit_casing_1side`):**  
   $$P = P_{leaf} + 2.5 \times P_{frame} + 2.5 \times P_{casing}$$
4. **Сценарий 4: «Комплект с наличниками на 2 стороны» (`kit_casing_2sides`):**  
   $$P = P_{leaf} + 2.5 \times P_{frame} + 5.0 \times P_{casing}$$
5. **Сценарий 5: «Комплект с доборами» (`kit_with_extensions`):**  
   $$P = P_{leaf} + 2.5 \times P_{frame} + 5.0 \times P_{casing} + 2.5 \times P_{ext}$$
6. **Сценарий 6: «Стандартный комплект с базовой фурнитурой» (`standard_kit_with_hardware`):**  
   **СТРОГО БЕЗ РУЧКИ!**  
   $$P_{std\_kit} = P_{leaf} + 2.5 \times P_{frame} + 5.0 \times P_{casing} + 2 \times P_{hinge} + P_{lock}$$
7. **Сценарий 7: «Полный комплект под ключ с ручкой» (`full_turnkey_kit`):**  
   $$P_{full} = P_{std\_kit} + P_{handle\_custom} + [P_{wc\_turn}]$$

## 3. Расчет составных доборов свыше 220 мм и норматив Н-профиля

При монтаже дверей в толстые несущие стены (кирпичные дома сталинской или современной монолитной застройки) толщина проема стены $T_{wall}$ часто составляет **260–450 мм**. Стандартных планок добора шириной 200 мм недостаточно.

```
       ┌──────────────────┐               ┌──────────────────┐
       │   Добор №1       │  ┌─────────┐  │   Добор №2       │
       │   (ширина W1)    │──┤ H-Beam  ├──│   (ширина W2)    │
       └──────────────────┘  └─────────┘  └──────────────────┘
```

### Правила и формулы для стен свыше 220 мм:
1. **Стыковка двух доборов:**  
   Две планки добора (например, 150 мм + 100 мм для стены 280 мм) соединяются вдоль проема через двухстороннюю соединительную соединительную Н-планку (`h_beam`).
2. **Норматив расхода Н-профиля:**  
   Подобно коробке и наличникам, соединительный профиль устанавливается по периметру проема:  
   **2 вертикальные стойки по 2070 мм + 1 горизонтальная перекладина напополам (1035 мм) = ровно 2.5 стойки Н-профиля.**
3. **Итоговая формула расчета составного добора:**  
   $$P_{ext\_compound} = 2.5 \times P_{ext1} + 2.5 \times P_{ext2} + 2.5 \times P_{h\_beam}$$

## 4. Правила совместимости сантехнической завертки `wc_turn`

Сантехнический фиксатор `wc_turn` функционирует только при соблюдении технической совместимости с замком и ручкой:

1. **Совместимость с замком:**  
   - Замок обязан иметь нижнее поворотное отверстие (follower) под квадратный шток сечением **6×6 мм** (стандарт AGB, Morelli) либо **8×8 мм** с комплектной переходной втулкой.  
   - Межосевое расстояние (расстояние между осью ручки и осью фиксатора) должно быть строго согласовано: стандарт сантехнических замков составляет **96 мм** (магнитные замки AGB Polaris / Morelli M1885) или **70 мм** (механические замки).
2. **Совместимость с ручкой (Дизайн и отделка):**  
   - *Форма розетки:* к ручке на квадратной розетке (серии Square / Q) подбирается фиксатор на квадратной розетке; к ручке на круглой розетке (серии Round / R) — на круглой розетке.
   - *Цветовой код:* код фиксатора обязан совпадать с ручкой: `BL` (черный матовый), `SN` (матовый никель), `CP` (глянцевый хром), `GL` (золото брашированное).
3. **Обработка в конфигураторе:**  
   При выборе ручки система автоматически фильтрует список совместимых заверток `wc_turn` по бренду, форме розетки и коду цвета, предлагая идеальную пару в 1 клик.

## 5. Проверка правила третьей петли для тяжелых полотен

- **Техническая ситуация:**  
  Царговые двери с толстым триплексом, сплошным зеркалом во весь рост (каталог Luxor, Двереки) весят от 35 до 48 кг.
- **Статус ограничения в системе:**  
  В связи с отсутствием прямого запрета на 2 петли в официальных каталогах производителей, данное правило переведено из статуса жесткой блокировки (`Hard Block`) в статус **мягкой технической рекомендации (`Soft Warning` / статус `unverified`)**.
- **Поведение интерфейса:**  
  Если вес полотна превышает 35 кг, а покупатель выбрал 2 петли:
  1. Корзина **НЕ блокируется**;
  2. Покупателю и менеджеру выводится ненавязчивая подсказка:  
     *«Рекомендация технолога: для тяжелого полотна со сплошным стеклом (вес > 35 кг) рекомендуется установка 3 петель во избежание провисания створки со временем»*;
  3. Клиент может оставить 2 петли либо добавить третью петлю одним кликом.
