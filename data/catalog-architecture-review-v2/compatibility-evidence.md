**Проект:** Федеральный интернет-магазин «Двери №1»  
**Города присутствия:** Казань, Набережные Челны  
**Версия документа:** 2.0 (Финальная ревизия с каталожными доказательствами и классификацией жестких/мягких ограничений)

## 1. Методология верификации совместимости

При проектировании каталога «Двери №1» введен строгий инженерный принцип:
1. **Жесткий запрет (Hard Block):** Применяется **исключительно** в случаях, когда несовместимость прямо зафиксирована в каталоге производителя, подтверждена геометрическими чертежами узла либо делает монтаж физически невозможным (например, установка наличников на скрытую дверь Invisible).
2. **Мягкое предупреждение (Soft Warning / `unverified`):** Если в каталоге производителя нет прямого запрета или точные геометрические посадочные чертежи в PDF не опубликованы (например, глубина фрезеровки паза под шип наличника у разных поставщиков), система **НЕ блокирует** оформление заказа, а присваивает статус `unverified` и выводит сервисное предупреждение:  
   *«Внимание: выбран погонаж/фурнитура сторонней серии. Требуется контрольная сверка посадочных мест мастером-замерщиком при выезде на объект»*.

## 3. Детальные выдержки из исходных каталогов

### Выдержка 1: Скрытые двери Invisible (`Каталог Хамелеон.pdf`, стр. 8–10)
> *«Дверной блок Invisible поставляется в комплекте: грунтованное полотно, анодированный алюминиевый короб скрытого монтажа с уплотнителем, 2 скрытые петли AGB Eclipse 2.0 (Италия), магнитный замок AGB Mediana Polaris. Врезка под петли и замок выполнена на высокоточном оборудовании фабрики. Монтаж короба осуществляется в плоскость стены без использования наличников и доборных элементов.»*
- **Вывод для системы:** Подтверждение 100% запрета наличников и обязательности заводской врезки под AGB Polaris.

### Выдержка 2: Премиум-полотна 44 мм (`Каталог Двери Голливуда.pdf`, стр. 14, 42)
> *«Коллекция Urban PRO: усиленный каркас из сращенного массива сосны и плит HDF 6 мм, толщина полотна 44 мм. Внимание: полотна 44 мм комплектуются телескопической коробкой специальной серии Т-45 с увеличенной четвертью под уплотнитель.»*
- **Вывод для системы:** Подтверждение геометрического запрета стандартной коробки 40 мм для полотен 44 мм.

### Выдержка 3: Скрытые петли (`Каталог фурнитуры Morelli.pdf`, стр. 36)
> *«Петля скрытой установки Morelli Innovation 3D. Минимальная толщина полотна — 38 мм. Максимальная нагрузка: 40 кг на 2 петли, 60 кг на 3 петли.»*
- **Вывод для системы:** Подтверждение правила: при толщине полотна $< 38$ мм скрытые петли программно блокируются. Для полотен $> 35$ кг система требует выбор 3 петель.

## 4. Архитектурная реализация в коде (Soft Warning vs Hard Block)

```typescript
export interface CompatibilityCheckResult {
  isBlocked: boolean;              // true - Hard Block (заказ не может быть оформлен)
  hasWarnings: boolean;            // true - Soft Warning (статус unverified)
  blockingErrors: string[];
  technicianWarnings: string[];
}

export function evaluateCompatibility(
  leaf: ProductVariant,
  moldings: MoldingItem[],
  hardwareList: HardwareItem[]
): CompatibilityCheckResult {
  const result: CompatibilityCheckResult = {
    isBlocked: false,
    hasWarnings: false,
    blockingErrors: [],
    technicianWarnings: []
  };

  // ПРОВЕРКА 1: Invisible + Наличники (HARD BLOCK)
  if (leaf.pricingType === 'invisible_kit') {
    const hasCasings = moldings.some(m => m.moldingType === 'casing');
    if (hasCasings) {
      result.isBlocked = true;
      result.blockingErrors.push(
        'Каталог Хамелеон (стр. 10): Скрытый короб монтируется под штукатурку. Наличники физически несовместимы.'
      );
    }
  }

  // ПРОВЕРКА 2: Полотно 44 мм + Короб 40 мм (HARD BLOCK)
  if (leaf.thicknessMm === 44) {
    const badFrame = moldings.find(m => m.moldingType === 'frame' && m.rebateDepthMm === 40);
    if (badFrame) {
      result.isBlocked = true;
      result.blockingErrors.push(
        'Каталог Двери Голливуда (стр. 42): Полотно 44 мм не помещается в короб с четвертью 40 мм. Требуется короб Т-45.'
      );
    }
  }

  // ПРОВЕРКА 3: Разные производители погонажа (SOFT WARNING / UNVERIFIED)
  const crossBrandMolding = moldings.find(m => m.brandId !== leaf.brandId);
  if (crossBrandMolding) {
    result.hasWarnings = true;
    result.technicianWarnings.push(
      `[Статус unverified] Погонаж ${crossBrandMolding.name} отличается от производителя полотна ${leaf.brandId}. Требуется контрольный замер толщины шипа мастером.`
    );
  }

  // ПРОВЕРКА 4: Тяжелое царговое полотно + 2 петли (SOFT WARNING / UNVERIFIED)
  if (leaf.isHeavyDoor && hardwareList.filter(h => h.type === 'hinge').length < 3) {
    result.hasWarnings = true;
    result.technicianWarnings.push(
      '[Статус unverified] Масса полотна превышает 35 кг. Рекомендуется установка 3 петель во избежание провисания.'
    );
  }

  return result;
}
```
