## 1. Концепция и Арт-дирекшн

Проект разработан в концепции **Luxury Architecture Editorial & Apple Store Experience**:
* **Эстетика Apple Liquid Glass**: полупрозрачные многослойные панели (`backdrop-filter: blur(20px)`), ультратонкие световые границы (`rgba(255, 255, 255, 0.12)`), чистый воздух и свободное пространство.
* **Строгая современная типографика**: чистый швейцарский гротеск без засечек (**Neue Haas Grotesk** в заголовках, **Inter** в интерфейсных элементах и таблицах). Запрет на антиквы и случайные шрифты.
* **Прозрачность и честность с клиентом**: отсутствие манипулятивных слоганов (никаких нереалистичных «бесплатная доставка за 1 час»). Реальные заводские цены (697 верифицированных моделей в базе), обоснованный расчет сметы на основе высокоточного лазерного замера геометрии проёмов инженером.

## 2. Архитектура и Структура проекта

Веб-приложение построено по модульной архитектуре с единым реактивным стором корзины, Node.js бэкендом, SMS-авторизацией и диспетчеризацией заказов:

```
├── index.html                   # Главная страница: Hero, галерея 4 категорий, витрина 697 товаров, фильтры
├── showrooms.html               # Флагманские шоурумы в Казани и Челнах, видеоэкскурсии, запись на визит
├── product.html                 # Страница товара: конфигуратор полотна, комплектации, сценариев и опций
├── cart.html                    # Спецификация и корзина: двухколоночный layout, 4-шаговый чекаут, SMS-код
├── app.css                      # Глобальная дизайн-система, переменные токенов, Apple Liquid Glass
├── app.js                       # Ядро витрины, динамические фильтры, карточки товаров, модальные окна
├── product.css / product.js     # Стили и интерактивная логика конфигуратора PDP
├── cart.css / cart.js           # Интерфейс спецификации, 4-шаговое модальное окно оформления заявки
├── cart-store.js                # Единый клиентский стор (localStorage 'DVER1_CART' + фоновая синхронизация)
├── server.js                    # Production Node.js сервер: статика, SMS Auth API, Orders REST API
├── robots.txt / sitemap.xml     # Поисковая оптимизация и индексация 700 URL для Казани и РТ
├── data/
│   ├── catalog-output/          # База каталога (products.json, product-variants.json, catalog-images/)
│   ├── orders/                  # Постоянное хранилище оформленных заявок (orders.json)
│   ├── carts/                   # Серверное хранилище синхронизированных корзин пользователей
│   └── sms/                     # Журнал отправки SMS-кодов верификации (sms_dispatch.log)
├── .env.example                 # Шаблон переменных окружения
└── README.md                    # Документация проекта
```

## 3. Каталог и Конфигуратор товаров

* **697 моделей от ведущих фабрик**: ProfilDoors, Феррони, Йошкар-Ола, Luxor, Chameleon Doors, ФСД, Двереки, Двери Голливуда и др.
* **4 ключевых архитектурных направления**:
  1. *Межкомнатные двери*: царговые, щитовые, эмаль, натуральный шпон, экошпон.
  2. *Входные сейф-двери*: двери с терморазрывом для загородных домов, шумоизоляционные для квартир.
  3. *Скрытые двери (Invisible)*: полотна под покраску и декоративную штукатурку с коробом скрытого монтажа.
  4. *Двери со стеклом*: матовый сатинат, художественный триплекс, зеркальные вставки.
* **Калькулятор комплектации на PDP**:
  * Расчёт сценариев: *Полный комплект с фурнитурой* (1.0), *Комплект без фурнитуры* (0.85), *Только полотно* (0.65).
  * Выбор ширины и высоты полотна (600/700/800/900 × 2000 мм, нестандарт до 2400–2700 мм).
  * Сторона открывания (Левое / Правое).
  * Дополнительные опции: сантехнический WC-фиксатор (+1 850 ₽), проверка проёмов инженером.

## 4. Корзина, SMS-верификация и Оформление

* **Корзина без обязательной предварительной регистрации**:
  * Добавление любого количества позиций из каталога и конфигуратора.
  * Персистентность через `localStorage` + фоновый `cart-store.js`.
  * Редактирование количества и удаление позиций с мгновенным пересчётом итогов.
* **4-шаговый сценарий оформления заявки**:
  1. *Контакты*: Имя, телефон РФ, выбор города (Казань / Набережные Челны).
  2. *SMS-верификация*: генерация 4-значного одноразового пароля (SHA-256 хэширование, срок 5 минут, лимит 5 попыток).
  3. *Параметры получения*: Самовывоз из салона / Доставка на объект специализированным транспортом, опция профессионального монтажа.
  4. *Подтверждение*: сводка спецификации, номер заявки вида `#D1-2026-XXXX`.
  * Интеграция с Telegram-ботом менеджеров с мягким фолбеком при отсутствии ключей.

## 5. Быстрый запуск

### Требования
* Node.js v18+

### Запуск локального сервера
```bash
# Клонирование репозитория
git clone https://github.com/archesnew/dver1.git
cd dver1

# Запуск бэкенда
node server.js
```
Сайт доступен по адресу: **http://localhost:3000**

## 6. Переменные окружения (.env)

Для перевода отправки SMS и уведомлений в production создайте файл `.env`:

```env
PORT=3000
NODE_ENV=production

# SMS-шлюз (SMS.RU)
SMS_API_KEY=ваш_api_ключ_sms_ru

# Уведомления дежурным инженерам шоурума
TELEGRAM_BOT_TOKEN=ваш_telegram_bot_token
TELEGRAM_CHAT_ID=id_чата_или_канала
```
> *Примечание:* если переменные не заданы, сервер автоматически функционирует в безопасном режиме разработки (коды фиксируются в `data/sms/sms_dispatch.log` и доступны через защищенный dev-эндпоинт для автотестов).

## 7. API Эндпоинты

| Метод | URL | Описание |
|---|---|---|
| `GET` | `/api/health` | Проверка статуса сервера и режима провайдеров |
| `POST` | `/api/auth/send-code` | Запрос 4-значного SMS-кода (rate-limit 60 сек) |
| `POST` | `/api/auth/verify-code` | Проверка SMS-кода и выдача session token |
| `POST` | `/api/cart/sync` | Фоновая синхронизация корзины клиента с сервером |
| `POST` | `/api/orders` | Фиксация заявки (серверная валидация цен, сохранение в `orders.json`) |
| `GET` | `/api/orders/:id` | Получение информации о созданной заявке |

## 8. Тестирование и Контроль качества

Проект покрыт автоматизированными тестами на базе Chrome / Edge DevTools Protocol (CDP):
* **Адаптивность**: 20 комбинаций витрин (390px, 430px, 768px, 1440px, 1920px) проверены на отсутствие горизонтального переполнения (`scrollWidth <= innerWidth`).
* **E2E сценарии**:
  * *Journey A*: Межкомнатная дверь с известной ценой (`PROD-CHAM-063`) + конфигурация опций + чекаут с SMS.
  * *Journey B*: Входная дверь (`PROD-FERR-001`) + самовывоз + чекаут.
  * *Journey C*: Смешанная спецификация из нескольких позиций, изменение количества, удаление, сохранение после перезагрузки страницы + заказ.

Запуск тестовых наборов:
```bash
node scratch/run_full_e2e_journeys.js
node scratch/audit_responsive_viewports.js
```
